Resumo de fórmulas

TemaFórmulaObservação
Juro simplesJ = C · i · ntaxa e prazo na mesma unidade de tempo
MontanteM = C · (1 + i · n)M = C + J
Taxas proporcionais2% a.m. = 24% a.a.vale no regime simples
Taxa médiaim = Σ(C·i) / ΣCmédia ponderada pelos capitais
Prazo médionm = Σ(C·n) / ΣCmédia ponderada pelos capitais
DescontoD = N − AN: valor nominal; A: valor atual
Desconto comercial (por fora)Dc = N · i · n
Ac = N · (1 − i · n)		percentual incide sobre N
Desconto racional (por dentro)Ar = N / (1 + i · n)
Dr = N − Ar		percentual incide sobre A
ComparaçãoDc = Dr · (1 + i · n)com mesma taxa e prazo, Dc > Dr
Taxa efetiva (desconto comercial)ief = Dc / Ac = i·n / (1 − i·n)sempre maior que i·n
Pergunta que resolve muita questão: o percentual está sendo aplicado sobre qual valor?
